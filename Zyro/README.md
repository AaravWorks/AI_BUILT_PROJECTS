# 🖐️ Zyro — Hand Gesture PC Controller

**Control your PC using hand gestures with Python and OpenCV.**

## 🚀 About

Zyro is an experimental computer vision project that explores touch-free PC interaction through hand gestures.

Built with Python and OpenCV, Zyro uses a camera to detect hand movements and translate supported gestures into computer actions.

The project focuses on exploring real-time hand tracking and gesture-based interaction without depending on cloud APIs.

## ✨ Features

- **Hand Gesture Recognition** — Detects supported hand gestures.
- **Real-Time Camera Input** — Uses a camera for live hand tracking.
- **PC Interaction** — Converts recognized gestures into computer actions.
- **Python & OpenCV** — Built using Python and computer vision technology.
- **Offline Approach** — Designed to perform its core processing locally without cloud AI APIs.

*Features and compatibility may vary depending on the project version and system configuration.*

## 🛠️ Technologies Used

- Python
- OpenCV
- Computer Vision
- Hand Tracking and Gesture Recognition
